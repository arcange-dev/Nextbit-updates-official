# NextBit Updates

NextBit Updates is a futuristic ICT news, learning and project platform focused on AI, software engineering, cybersecurity, electronics, robotics, hardware, IoT and African technology.

## Frontend included
- Premium black/orange responsive design
- Animated technology hero and ticker
- Newsroom, article reader and source verification UI
- Search and category filtering
- Understand the Bit: beginner/developer/engineer
- NextBit AI workspace UI ready for LLM integration
- Software, electronics and cybersecurity learning sections
- Learning paths, lesson workspace and progress UI
- Hands-on project catalog and project detail UI
- Africa Tech and Rwanda Tech
- Profiles, bookmarks, notifications and settings
- Login/register UI ready for Supabase Auth
- About, Contact, Privacy and Terms
- Admin dashboard, editorial workflow and article editor
- Source management, users, moderation and analytics UI
- Newsletter workflow UI
- Accessibility and reduced-motion support

## Stack
React 19 · TypeScript · Vite · Tailwind CSS v4 · Lucide React

## Production integrations planned
Supabase/PostgreSQL, Supabase Auth, Supabase Storage, an LLM API for NextBit AI, RSS/permitted publisher APIs for news ingestion, Resend/equivalent email, and Vercel Analytics/PostHog.

## Run
npm install
npm run dev
